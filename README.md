# امتحان الوحدة الأولى — Virelo Academy (ICT)

موقع امتحان إلكتروني كامل (اختيار من متعدد) لمادة ICT — الصف الثاني الثانوي — الوحدة الأولى:
تكنولوجيا المعلومات والمجتمع. مبني بالكامل بـ **HTML5 + CSS3 + JavaScript خام (Vanilla JS)**
بدون أي إطار عمل (لا React ولا Vue ولا Bootstrap)، ويحفظ نتائج الطلاب في **Google Sheets** عبر
**Google Apps Script**.

---

## 1) نظرة عامة على المشروع

التدفق الكامل للطالب:

```
شاشة التسجيل (الاسم الثلاثي + رقم الهاتف)
        ↓
شاشة تعليمات الامتحان
        ↓
الأسئلة (50 سؤال اختيار من متعدد) + مؤقّت + لوحة تنقّل
        ↓
تأكيد الإنهاء + تنبيه الأسئلة بدون إجابة
        ↓
حساب النتيجة وعرضها
        ↓
حفظ النتيجة تلقائيًا في Google Sheets
```

الامتحان يعمل بالكامل من المتصفح مباشرة (Static Website)، ولا يحتاج أي خادم خلفي خاص بك —
فقط رابط Google Apps Script الذي ستنشئه بنفسك (خطوات كاملة أدناه).

## 3) التشغيل محليًا (على جهازك)

لا تحتاج أي تثبيت (لا npm ولا build). فقط:

1. افتح مجلد `virelo-unit1-exam` بأي محرر (مثل VS Code).
2. شغّل خادمًا محليًا بسيطًا (لأن بعض المتصفحات تمنع تحميل ملفات JS عبر `file://` مباشرة):
   - إن كان لديك بايثون: `python3 -m http.server 8000` من داخل المجلد، ثم افتح
     `http://localhost:8000` في المتصفح.
   - أو استخدم إضافة "Live Server" في VS Code.
3. جرّب الامتحان كاملًا (بدون رابط Google Sheets، ستظهر رسالة توضح أن الحفظ غير مُفعّل بعد،
   وتظل النتيجة معروضة على الشاشة — هذا سلوك متعمّد وليس خطأ).

## 4) إضافة شعار Virelo الحقيقي

1. احصل على ملف الشعار الرسمي بصيغة PNG (خلفية شفافة يُفضّل).
2. استبدل الملف الموجود في:
   ```
   assets/virelo-logo.png
   ```
3. لا تُغيّر اسم الملف أو مساره (أو غيّر المسار في `js/config.js` → `logoPath` وفي وسوم
   `<img>` داخل `index.html` إذا اخترت اسمًا مختلفًا).
4. حافظ على أبعاد الشعار وتناسقه — لا تُشوّه أبعاده الأصلية.

## 5) تعديل أسئلة الامتحان

كل الأسئلة موجودة في:

```
js/questions.js
```

بالشكل التالي:

```js
{
  id: 1,
  question: "نص السؤال هنا؟",
  options: [
    "الاختيار الأول",
    "الاختيار الثاني",
    "الاختيار الثالث",
    "الاختيار الرابع"
  ],
  answer: 2   // فهرس الاختيار الصحيح (يبدأ من 0) — هنا "الاختيار الثالث"
}
```

**قواعد مهمة:**
- يجب أن يبقى عدد الأسئلة **50 بالضبط** (أو غيّر `CONFIG.totalQuestions` في `config.js` ليطابق
  العدد الجديد — الاثنان يجب أن يتطابقا دائمًا).
- كل سؤال يجب أن يحتوي على **4 اختيارات بالضبط**.
- `answer` رقم من 0 إلى 3 فقط (0 = الاختيار الأول، 1 = الثاني، 2 = الثالث، 3 = الرابع).
- الموقع يتحقق تلقائيًا من هذه القواعد عند التحميل، وإن وُجد خطأ سيظهر لك رسالة خطأ واضحة
  بدل تشغيل امتحان غير مكتمل بصمت.

## 6) تغيير مدة الامتحان (المؤقّت)

داخل `js/config.js`:

```js
examDurationMinutes: 60,
```

- غيّر الرقم لأي مدة بالدقائق تريدها.
- لإلغاء المؤقّت تمامًا (امتحان بلا وقت محدد):
  ```js
  examDurationMinutes: null,
  ```

## 7) إعداد Google Sheets خطوة بخطوة

### الخطوة 1: أنشئ ملف Google Sheets جديد
اذهب إلى [sheets.google.com](https://sheets.google.com) وأنشئ ملفًا جديدًا فارغًا.

### الخطوة 2: أنشئ ورقة باسم "Exam Results"
أضف ورقة (Sheet/Tab) جديدة داخل نفس الملف، وسمّها بالضبط:
```
Exam Results
```
(الكود سينشئها تلقائيًا بهذا الاسم إن لم توجد، لكن يُفضّل إنشاؤها يدويًا للتأكد).

### الخطوة 3: الأعمدة (Headers)
لا داعي لكتابتها يدويًا — كود `Code.gs` يكتبها تلقائيًا في أول عملية إرسال ناجحة:

| Timestamp | Student Name | Phone Number | Exam Name | Subject | Grade | Unit | Score | Total | Percentage | Correct Answers | Wrong Answers | Unanswered | Duration | Submission Status | Submission ID |

### الخطوة 4: افتح محرر السكريبت
من داخل ملف الشيت: **Extensions → Apps Script** (الإضافات ← أبس سكريبت).

### الخطوة 5: الصق الكود
احذف أي كود موجود بالكامل، وانسخ محتوى الملف:
```
google-apps-script/Code.gs
```
والصقه كاملًا في المحرر، ثم احفظ (Ctrl+S / Cmd+S).

### الخطوة 6: انشر كتطبيق ويب (Deploy → Web app)
من زر **Deploy** أعلى اليمين → **New deployment**:
- اختر النوع (Select type): **Web app**.

### الخطوة 7: إعدادات النشر
- **Execute as (تنفيذ باسم):** Me (حسابك أنت).
- **Who has access (من يملك الصلاحية):** Anyone (أي شخص) — هذا ضروري حتى يستطيع موقع
  الامتحان الاتصال بالسكريبت دون تسجيل دخول Google.

اضغط **Deploy**، وقد تُطلب منك الموافقة على الصلاحيات (Authorize access) — وافق باستخدام
حسابك.

### الخطوة 8: انسخ رابط تطبيق الويب (Web App URL)
بعد النشر ستظهر لك رابط بالشكل:
```
https://script.google.com/macros/s/XXXXXXXXXXXXXXXXXXXXX/exec
```
انسخه بالكامل.

### الخطوة 9: الصق الرابط في الإعدادات
افتح `js/config.js` وضع الرابط هنا:
```js
googleScriptUrl: "https://script.google.com/macros/s/XXXXXXXXXXXXXXXXXXXXX/exec",
```

### الخطوة 10: اختبر الإرسال
- افتح الرابط نفسه مباشرة في المتصفح؛ يجب أن تظهر رسالة JSON بسيطة تؤكد أن الخدمة تعمل.
- أكمل امتحانًا تجريبيًا كاملًا من موقعك، وتأكد من ظهور صف جديد في ورقة **Exam Results**.

> **ملاحظة عن CORS:** الطلب يُرسل بصيغة `fetch(url, { headers: { "Content-Type":
> "text/plain;charset=utf-8" } })` بدلًا من `application/json` عمدًا؛ لأن Google Apps Script
> لا يدعم طلبات Preflight (OPTIONS) الخاصة بـ CORS مع `application/json`، بينما `text/plain`
> يتفادى هذا القيد تمامًا مع بقاء المحتوى الفعلي (`body`) نصًا يمثّل JSON صالحًا يُفكّكه
> `JSON.parse()` داخل `Code.gs` بشكل طبيعي. **لا تُغيّر نوع الرأس (header) هذا** إلا إذا كنت
> تعرف بالضبط ما تفعله.

> **كل استجابة من الخادم بصيغة JSON موحّدة:**
> ```json
> { "success": true, "message": "تم حفظ النتيجة بنجاح." }
> ```
> أو عند الخطأ:
> ```json
> { "success": false, "message": "وصف الخطأ هنا" }
> ```

## 8) النشر على الإنترنت (مثال: Vercel)

الموقع بالكامل عبارة عن ملفات ثابتة (Static)، لذا يمكن نشره على أي استضافة ثابتة مجانية.

**عبر Vercel:**
1. أنشئ حسابًا على [vercel.com](https://vercel.com) (يمكن الدخول مباشرة بحساب GitHub).
2. ارفع مجلد المشروع كمستودع (repository) على GitHub، أو استخدم Vercel CLI:
   ```
   npm install -g vercel
   cd virelo-unit1-exam
   vercel
   ```
3. اتبع التعليمات على الشاشة (لا حاجة لأي إعدادات بناء (Build) خاصة — الموقع ثابت بالكامل).
4. بعد النشر، ستحصل على رابط مباشر يمكنك مشاركته مع الطلاب.

يعمل الموقع بنفس الطريقة على أي استضافة ثابتة أخرى (GitHub Pages, Netlify, Cloudflare Pages...).

## 9) اختبار الامتحان قبل تسليمه للطلاب

قائمة اختبار سريعة (راجعها قبل الاستخدام الفعلي):

- [ ] تسجيل باسم أقل من 3 كلمات → يظهر خطأ واضح.
- [ ] تسجيل برقم هاتف غير مصري / غير صحيح → يظهر خطأ واضح.
- [ ] تسجيل ببيانات صحيحة → الانتقال لشاشة التعليمات.
- [ ] كل الأسئلة الـ 50 تظهر بالترتيب الصحيح دون نص مفقود.
- [ ] أزرار "التالي" و"السابق" تعمل بسلاسة، وتُعطَّل عند الحدين.
- [ ] لوحة التنقّل تعكس حالة كل سؤال (بدون إجابة / تمت الإجابة / الحالي).
- [ ] تغيير الإجابة المختارة أكثر من مرة يعمل بشكل صحيح.
- [ ] عند وجود أسئلة بدون إجابة والضغط على "إنهاء الامتحان" → تظهر نافذة التنبيه بالعدد الصحيح.
- [ ] المؤقّت يعمل ويُسلّم الامتحان تلقائيًا عند الوصول للصفر.
- [ ] النتيجة (صحيح/خطأ/بدون إجابة/النسبة) صحيحة حسابيًا.
- [ ] الإرسال لـ Google Sheets ينجح ويُخزَّن صف جديد بكل البيانات.
- [ ] عند قطع الإنترنت أثناء الإرسال: تظهر رسالة "تعذّر الحفظ" مع بقاء النتيجة ظاهرة وزر
      "إعادة محاولة الحفظ".
- [ ] الضغط على "إعادة محاولة الحفظ" عدة مرات لا يُنشئ صفوفًا مكررة بعد نجاح الحفظ.
- [ ] تحديث الصفحة (Refresh) أثناء الامتحان يُظهر تحذير المغادرة (beforeunload) قدر دعم المتصفح.
- [ ] العرض على الموبايل: لا تمرير أفقي، الأزرار كبيرة بما يكفي للمس، النص واضح.
- [ ] العرض على الحاسوب المكتبي وسطح المكتب.
- [ ] اتجاه الصفحة RTL صحيح في كل الشاشات، والخط العربي واضح.
- [ ] لا توجد أي أخطاء في الـ Console (افتح أدوات المطوّر → Console).

## 10) استكشاف الأخطاء الشائعة (Google Sheets)

| المشكلة | السبب المحتمل | الحل |
|---|---|---|
| رسالة "تعذّر حفظ النتيجة على الخادم حاليًا" دائمًا | لم تُعدّل `googleScriptUrl` بعد، أو الرابط خاطئ | تأكد من نسخ الرابط كاملًا وبدون مسافات من خطوة النشر |
| خطأ CORS في الـ Console | تم تغيير نوع الـ header إلى `application/json` | أعده إلى `text/plain;charset=utf-8` كما في الكود الأصلي |
| لا تظهر أي بيانات في الشيت رغم رسالة "تم الحفظ بنجاح" | قد تكون فتحت ملف Sheets مختلفًا عن الذي يحتوي السكريبت | تأكد أن Apps Script مربوط بنفس ملف Google Sheets الذي تراجعه |
| رسالة "Authorization required" عند فتح رابط السكريبت | لم تُكمل خطوة الموافقة على الصلاحيات | أعد عملية Deploy ووافق على كل الأذونات المطلوبة |
| تغييرات الكود لا تظهر بعد تعديل `Code.gs` | كل تعديل يحتاج نشرًا جديدًا | من Deploy → Manage deployments → عدّل النشر الحالي (Edit) → Deploy مجددًا |
| الأعمدة بترتيب مختلف عن المتوقع | تم تعديل يدوي في صف العناوين | احذف الصف الأول واترك الكود يعيد إنشاءه تلقائيًا في الإرسال التالي |

## 11) تنبيه أمني مهم (اقرأه قبل الاستخدام الرسمي)

هذا امتحان تعليمي بسيط، **وليس منصة اختبارات عالية الأمان**. بما أن الإجابات الصحيحة موجودة
داخل ملف `js/questions.js` الذي يُحمَّل في متصفح الطالب، فإن أي طالب لديه معرفة تقنية كافية
(فتح أدوات المطوّر وقراءة كود الصفحة) يمكنه نظريًا الوصول إلى الإجابات الصحيحة. هذا النظام
**لا يوفر حماية كاملة ضد الغش**، ويُناسب الاستخدام التعليمي العادي (واجبات، اختبارات قصيرة،
مراجعات ذاتية) وليس الامتحانات الرسمية عالية الحساسية.
